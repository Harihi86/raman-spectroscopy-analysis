# Publication scope

This repository was initialized with a clean history for a personal public
portfolio. Its root MIT license covers owner-authored software and original
explanations included here, not third-party books, external dependencies or
unreleased scientific data.

The release includes an explicit small source selection, tests and synthetic or
mathematical examples. It excludes credentials, environment files, internal
orchestration/deployment configuration, private service addresses, private task
records, correspondence, restricted datasets, old run logs and copied Git history.
Dependencies are installed normally under their respective licenses; their source
is not vendored. External references are links and original summaries.

Public examples must be generated from the documented commands. Runtime output
under `runs/` is ignored and should be reviewed before sharing, since user-supplied
paths, commands, source or scientific data can contain private information.
