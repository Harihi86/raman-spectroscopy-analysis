# 中文常见问题与排错

## 找不到 raman-analyze 命令

确认已在当前虚拟环境安装仓库。也可以直接调用模块：

```bash
python -m raman_analysis.cli --lang zh --help
```

Windows 可用 `.venv\Scripts\python.exe -m raman_analysis.cli ...`，无需更改全局执行策略。

## 清单文件有效，但仍有 BLOCKED

`validate` 主要检查结构。加 `--check-files` 会读取文件并校验列；实际模型参数还需在拟合时满足数据范围与点数要求。
查看 `report.html` 中该 ID 的诊断，确认文件路径以清单所在目录为基准，列名与表头完全一致，单位是 cm^-1。

## 输入没有误差列

删除 `input.sigma`。程序会使用残差缩放的局部误差模型，不应人为填入不明来源的测量误差。

## 只有光谱，没有压力

在 `tracking` 中写 `{"enabled":false}` 可只做批量光谱分析。
若启用追踪，缺压力的记录仍保留拟合结果，但不能更新压力轨迹，总状态会保留不确定性。

## 为什么不自动排序压力或平均重复点

采集顺序可以区分重复测量、减压和不同状态。重复压力不是重复身份。
程序按清单顺序和独立 `series` 处理，并保留每次采集。

## 为什么峰交叉处没有确定编号

检查 `candidate_track_ids`、拟合可辨识性、预测模型和实验分辨率。
存在多个全局竞争配对时，正确结果是保留 AMBIGUOUS。降低阈值只能改变规则，不能凭空增加物理证据。

## 为什么 INCONCLUSIVE，但优化器显示收敛

可能存在平坦/线性输入、不可辨识峰、参数触界、协方差条件差、残差相关或噪声失配。
查看逐谱 `report.json` 和残差。优化器收敛与科学模型可靠性是不同证据层次。

## AsLS/arPLS 拒绝不均匀横坐标

该方法的惩罚项作用在采样索引上，依赖近似均匀采样。可选择有明确参考区间的多项式基线，
或显式设置 `"resample":true`，仅将基线估计放在均匀网格上，再映射回原始坐标。拟合和导出的原始谱点保持不变。

## 中文名称在表格中乱码

新批处理汇总使用 UTF-8 BOM。选择电子表格的 UTF-8 导入方式，并保持原 CSV 编码。
`id` 使用简单字母数字，中文显示名写在 `label`；中文文件路径本身受支持。

## 为什么同一文件能在清单出现多次

一个 Excel 工作簿或共享 X 表可以容纳多条谱。为每条记录指定自己的列/工作表、ID 和实际压力即可。
输入文件相同不等于光谱身份相同。

## 已有输出目录不能再次运行

选择新的结果目录。这样能保留旧参数、错误记录与追踪证据，不会混合两次运行。
调整追踪参数可使用 `track`，它复用完成批次的拟合结果。

## 中断后如何处理

查看 `run.json` 与 `spectra.jsonl`。只有 COMPLETE 的完整报告才可重新追踪。
当前没有自动续跑；可将剩余 ID 整理成新清单继续处理，保存原批次作为部分结果。

## 为什么图片的坐标轴是英文

控制台、结果总览和使用文档支持中文。图轴采用通用的英文物理量及单位，避免不同平台缺少中文字体造成图形乱码。
数值可从 CSV 导出，按论文或报告格式重新绘图。

## 旧 SHproject 能否直接全部复现

保留的 legacy 代码包含实验专用假设和历史 NumPy 接口。参见 [legacy 审计](legacy-audit.md)。
新 API 不导入旧 profile；旧实验图与真实数据分析仍需兼容环境和独立验证。

## 自动峰数为什么达到上限或与肉眼不同

达到 `max_peaks` 只表明当前搜索没有排除更复杂模型，不能确认为该峰数。查看候选代价、残差、参数边界和竞争峰数；尝试有物理依据的窗口及基线，并比较结果是否稳定。荧光背景、尖峰、负向异常和不匹配或非对称线型可能被额外组分吸收。不要只增大上限或关掉残差告警来制造 PASS。

## 零峰结果是否说明样品没有 Raman 模式

不说明。零峰表示在当前数据、噪声模型、窗口和候选线型下，没有得到更受支持的正组分。弱峰、重叠、分辨率和背景均可能限制判断。

## 无表头 Excel 的第一行为何重要

设置 `input.header:null` 并用整数列索引。默认 `header:0` 将第一行当作表头；程序不会自行猜测表格格式。

## arPLS 有曲线但没有收敛

查看 `baseline_diagnostics` 的迭代数、相对权重变化及终止原因。
有限预算耗尽和负残差统计退化都会保留 INCONCLUSIVE；有一条平滑曲线不等于基线正确。
请在预先确定的合理基线设置中检查稳定性，不能只保留最容易通过的一组。

## 三种峰型给出不同峰数

查看每种峰型内部的最佳候选和 `shape-comparison.csv`/PNG，而不只看总分最低的一行。
Gaussian/Lorentzian 每峰 3 个参数，Voigt 每峰 4 个参数，程序按实际自由参数惩罚。
峰型分歧会保留为 INCONCLUSIVE；它可能来自真实线型、背景、重叠、尖峰或局部搜索不足。
具体配置及 `stability` 命令见[基线和峰型指南](profiles-and-baselines.zh-CN.md)。
